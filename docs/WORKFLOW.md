# Workflow — source files to management report

1. Reconcile actuals to the ledger and budget to the approved plan. Recalculate and save Excel files.
2. Create a company; select reporting currency, fiscal start, number format and signs.
3. Select actual, budget and optional forecast sheets. Map columns and inspect the preview.
4. Review errors. Correct values, currencies, duplicate IDs and conflicting classifications. Exclude invalid rows only after considering their financial significance; retain the issue export.
5. Review missing periods, categories, dimensions and plans. Default to unavailable. Approve zero only with evidence. Do not confirm completeness merely to obtain a profit figure.
6. Apply the reviewed snapshot, session-only or explicitly remembered. Failed imports preserve the previous snapshot.
7. Select month, monthly/YTD mode, dimensions and one budget/forecast version. Read coverage notices before relying on totals or ratios.
8. Investigate account detail and source rows. Obtain operational evidence before attributing causes or proposing actions.
9. Review twelve future forecast months. Missing months remain unavailable; slider sensitivities are unapproved.
10. Export, reconcile and archive externally. The app is not a backup or formal approval register.

Refresh via Import files on the active company: append or replace after review. Use unique source IDs to detect repeated actuals. Revised plans need distinct versions rather than duplicate observations in the same version.
